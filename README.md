# Freaky Fashion

Freaky Fashion is a full-stack web application developed as part of an educational assignment to demonstrate my knowledge of Angular.

The project focuses on building a structured, component-based application with a separate frontend and backend.

The application is based on an e-commerce concept, providing an opportunity to work with frontend architecture, routing, data handling, and communication between the client and server.

## Technologies

**Frontend**
- Angular
- TypeScript
- HTML5
- CSS

**Backend**
- Separate server-side application
- API integration for communication between frontend and backend

## Project Structure

```text
Freaky-Fashion/
├── client/          # Angular frontend application
├── server/          # Backend application
├── .gitignore
└── README.md
```

## Getting Started

### Prerequisites

- Node.js
- npm
- Angular CLI

### Installation

Install the frontend dependencies:

   ```bash
   cd client
   npm install
   npm run dev
   ```

Start the Angular development server:

   ```bash
   cd server
   ng serve
   ```

### Backend

The backend is located in the server directory and uses SQLite as its database management system.

The backend handles database operations and exposes data to the Angular frontend through an API.

The backend must be configured and started separately according to its dependencies.
